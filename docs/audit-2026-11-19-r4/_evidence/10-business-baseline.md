# 证据 10 · 直播电商业务基准（外部调研）

> 调研时间：2026-11-19，联网核实，优先官方文档
> 用途：判断系统「是否贴近业务」的外部标尺，不以系统菜单为标准

## 1. 代运营团队真实作业链（T-7 → T+2）

| 阶段 | 关键动作 | 产出物 | 主责 |
|---|---|---|---|
| T-7 目标 | 定 GMV/ROI/场观，拆品类与场次 | 目标表、预算表 | 运营 + 财务 |
| T-5 选品 | 毛利、库存、履约、竞品价、历史转化 | 选品评估表 | 运营 + 供应链 |
| T-3 排品 | 引流/利润/福利/憋单组合，排讲解顺序与时长 | 排品表 | 运营 + 编导 |
| T-2 排班 | 主播/场地/设备/手卡/背景 | 排期表 | 运营助理/HRBP |
| T-1 预热 | 短视频 3–10 条、私域、投流计划 | 素材、预约数据、计划表 | 拍剪 + 投手 |
| T0 开播 | 拉人气 → 跑投产 → 逼单；改价/改库存/上链接 | 盯盘与异动处理记录 | 全员 |
| T0 下播 | 结算、催付、异常订单、库存回滚 | 场次结算单 | 中控 + 客服 |
| T+1 履约 | 发货、超时预警、退款/售后、差评 | 履约日报、售后工单 | 客服 + 仓储 |
| T+1~2 复盘 | 流量/转化/货品/投放/话术五维 | 复盘报告 + 行动项 | 运营 |

单场人力约 50–70 人时；播前 30–35%、场中 40–45%、播后 20–25%。

### 必须有系统的 7 件事
1. 多店铺/多品牌数据聚合与口径统一
2. 以「场次」为主键的关联（排品/讲解/投放/订单/退款）
3. 主播排班与工时/结算
4. 多平台商品/价格/库存/活动一致性
5. 售后/履约超时监控
6. 合规留痕（法定 3 年）
7. 复盘与行动项闭环

### Excel/IM 就够的 6 件事（不要过度设计）
1. 单品牌单场选品打分与排品
2. 临时沟通与换班
3. 创意脑暴、脚本初稿
4. 小团队日报/周报
5. 达人与服务商关系维护
6. 单场排期

## 2. KPI 口径（同名不同义）

| 指标 | 正确口径 | 常见错误 |
|---|---|---|
| 抖店成交金额 | 支付成功或货到付款确认，**不剔退款**；直播期间=全渠道 | 与「退款后 GMV」混用 |
| 净成交金额（千川） | 成交金额 − **支付后 1 小时内退款**（秒退） | 未区分秒退 |
| 净成交 ROI | 净成交金额 ÷ 消耗 | 用支付 GMV 算 |
| GPM | 支付 GMV ÷ **看播 PV** × 1000 | 用场观人数做分母 |
| UV 价值 | 成交金额 ÷ 直播间 PV | 用 UV 人数 |
| 转化率 | 至少 3 种分母：进入人数 / 曝光人数 / 商品点击人数 | 不写全称 |
| 整体 ROI vs 投放 ROI | 整体含自然流量；投放只算广告直接成交 | 两者混用 |
| 拼多多 | **千次进人成交**（分母是进入人数） | 当 GPM 用 |

## 3. 六平台差异（必须差异化 vs 可统一）

| 平台 | 形态 | 专属指标/动作 | 开放能力边界 |
|---|---|---|---|
| 抖音 | 内容+交易双场，M1/M2/M3 三池 | GPM、UV 价值、净成交 ROI、综合营销 ROI、达人 L0–L6 | 自研只能自用；服务市场有资金/人员门槛 |
| 淘宝/天猫 | 店铺经营为主，直播是工具 | 生意参谋、万相台无界-超级直播、直播间成长 | **自研仅限天猫卖家，C 店不支持** |
| 小红书 | 笔记蓄水 → 直播转化（NPL） | GPM 权重最高；笔记预约转化 | 服务商/商家自研；直播数据 API 未核实 |
| 视频号 | 公私域联动 | 进房成本、观看成交转化、新客占比 | 微信小店 + 权限集 175 |
| 快手 | 老铁私域 + 直播 | 付费 ROI/首日 ROI、粉丝复购 | 电商开放平台 + 磁力金牛 |
| 拼多多 | 低价货架为主，直播为辅 | **千次进人成交**、复购成交占比、净交易额 | 商品/推广/订单；直播 API 未核实 |

**必须差异化**：指标口径、授权链路、场中动作、内容形态、合规要求。
**可以统一**：组织权限、排期排班、商品主数据、素材/脚本库、复盘模板、告警引擎、财务核算。

## 4. 必须具备的 13 条能力

多平台授权与 token 生命周期 / 指标字典与口径层 / 场次主键数据模型 / 排品排期排班协同 / 分钟级盯盘告警 / 投放-素材-成交归因 / 订单售后履约闭环 / 复盘+行动项闭环 / 素材脚本资产库 / 合规审核留痕 / 多品牌权限隔离 / 单场 P&L / AI 产出可追溯与人工复核。

## 5. 8 条伪需求

1. 直播间流量池等级/层级预测（官方无定义）
2. 场中全自动调控（自动改价/改库存/上下架）
3. 六平台一键开播/改价/发券
4. AI 全自动主播/选品/投放
5. 跨平台统一 KPI 排行榜
6. 直播间 3D 数字孪生
7. 自建平台级 BI 替代罗盘/生意参谋
8. AI 实时违禁词 100% 拦截

## 6. 审计访谈 10 问（用于现场验真）

1. 演示拉取昨天一场直播的分钟级数据，接口是哪个、延迟多少？
2. 抖音应用是自研型还是服务商型？多品牌授权怎么合规？
3. GMV 是哪个口径？含不含退款？和千川净成交差多少？
4. GPM 的分母是什么？字段定义在哪？
5. 有「流量池等级」吗？数据从哪来？
6. 数据发生到告警端到端多久？断流怎么办？
7. 排品与库存/价格联动吗？改价走哪个接口？
8. 投流复盘能拆到计划/素材/人群包三层吗？素材衰减怎么定义？
9. 违禁词库版本/来源/更新频率？有 3 年留痕吗？数字人怎么标识？
10. AI 脚本的 prompt 版本、模型版本、人工修改率、失败样本库在哪？多品牌数据怎么隔离？

## 7. 合规硬约束

- 《直播电商监督管理办法》（2026-02-01 施行）：交易信息、选品核验、纠错记录**留存 ≥3 年**；AI 生成人物**持续标识**；切片通常构成商业广告。
- 《AI 生成合成内容标识办法》（2025-09-01 施行）：显式 + 隐式标识。
